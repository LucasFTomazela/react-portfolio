# My Portfolio

This is my personal portfolio, developed using **React**. Here you can find information about me, my projects, skills, and how to contact me.

## 🚀 Technologies Used

This project was developed using the following technologies:

### Main Dependencies
- [React](https://reactjs.org/) - Library for building user interfaces.
- [React DOM](https://reactjs.org/docs/react-dom.html) - Integration of React with the DOM.
- [i18next](https://www.i18next.com/) - Library for internationalization.
- [React i18next](https://react.i18next.com/) - Integration of i18next with React.
- [@fontsource/outfit](https://fontsource.org/fonts/outfit) - Custom font "Outfit".
- [@fontsource/roboto](https://fontsource.org/fonts/roboto) - Custom font "Roboto".

### Development Dependencies
- [Vite](https://vitejs.dev/) - Tool for fast project development with React.
- [ESLint](https://eslint.org/) - Linting tool to ensure high-quality code.
- [@vitejs/plugin-react](https://vitejs.dev/plugins/react/) - Plugin for integrating React with Vite.
- [ESLint Plugin React](https://github.com/jsx-eslint/eslint-plugin-react) - Additional rules for React.
- [ESLint Plugin React Hooks](https://github.com/facebook/react/tree/main/packages/eslint-plugin-react-hooks) - Validation of specific rules for React Hooks.
- [Globals](https://github.com/sindresorhus/globals) - List of global variables.
- [@types/react](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react) - TypeScript typings for React.
- [@types/react-dom](https://github.com/DefinitelyTyped/DefinitelyTyped/tree/master/types/react-dom) - TypeScript typings for React DOM.

## 🎯 Features
**- Internationalization:** The project supports multiple languages using ``i18next`` and ``react-i18next``.

**- Custom Styling:** Utilizes "Outfit" and "Roboto" fonts for a modern and clean design.

**- Performance:** Optimized configuration with Vite for fast loading.
